# 1-1(mission1) 질문하며 기획하고 HTML 첫 버전 만들기

코디세이 AI 네이티브 입학연수과정 미션1 제출물.

- **미션:** AI의 질문에 답하며 기획서를 정리하고, 같은 기획서로 두 AI에게 HTML 첫 버전을 받아 비교함.
- **한 것:** 영화 티어리스트 기획. S~D 5단계(무지개색), 끌어다 놓기, 새로고침 후 유지, 제목+이모지 카드로 정함. Claude(A)·ChatGPT(B)에게 같은 기획서로 HTML을 받아 같은 행동으로 비교함.
- **결과:** 수정 없이 모두 동작하고 기획서와 더 잘 맞는 A 선택. B는 저장 이미지에서 이모지가 제목에 겹쳐 따로 고침.
- **완성본:** `html/영화_A_초안(영화_A_v1_Claude).html`

## 파일 이름 규칙

- 폴더 안은 `html/`(페이지), `md/`(기획서·기록), `대화 캡처/`(AI와 나눈 주요 대화)로 나눔.
- 대화 캡처는 `AI이름_대화캡처번호.png`로 저장. 예: `claude_대화캡처1.png`, `chatgpt_대화캡처1.png`.
- 1-1은 앞에 A/B와 버전을 붙임. 예: `A_v1_Claude_대화캡처1.png`, `B_v2_ChatGPT_대화캡처1.png`.
